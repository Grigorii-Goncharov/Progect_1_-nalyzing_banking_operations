
# "Аnalyzing banking operations"

Приложение для анализа банковских транзакций, которые находятся в Excel-файле. Приложение генерирует JSON-данные для веб-страниц, формирует Excel-отчеты и др.

Данный проект реализует анализ данных, в нем используется 3 модуля:

1. Главная страница
2. Генерация финансовых отчётов по категории и дате операции
3. Функция фильтрации трат по категориям

## Описание

Проект состоит из следующих модулей:

- `views` - модуль работающий с помощью "utils" и возвращающую JSON. Ниже по модульно представлена работа
- `utils` - модуль, в котором находятся функции для работы проекта,
- `services` - Функция фильтрации трат по категории повышенного кешбэка. Формирует JSON
- `reports` - модуль - декоратор для фильтрации транзакций по категории и дате.

## Установка

Для установки и запуска проекта необходимо выполнить следующие шаги:

1.  **Клонируйте репозиторий:**

    ```
    git clone git@github.com:Grigorii-Goncharov/Progect_1_-nalyzing_banking_operations.git
    ```

2.  **Перейдите в папку проекта:**

    ```
    cd Progect_01_Аnalyzing_banking_operations
    ```

## Зависимости
Зависимости проекта управляются через Poetry. Они перечислены в файле `pyproject.toml`



## Тестирование
